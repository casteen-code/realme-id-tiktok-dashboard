# 每次换 campaign 的工作流程

## 保留版式，只换活动素材

打开现有 HTML 或保存的项目，先改顶部活动名称。逐个选择左侧图层并替换素材。原来的位置、缩放、支点和动画会保留；新图按旧图高度适配比例。修改普通文字，检查前后遮挡，然后导出。

左右装饰和小猫已独立，背景里没有重复的小猫或标题。背景中的海天与舞台作为一个场景图层管理。若下一场需要海面、云、地面各自运动，请让 GPT 把它们另外分层输出。

## 从空白活动开始

点击“新活动”，再点“背景”选择底图。添加主题、产品和装饰；用“上移一层 / 下移一层”调整前后遮挡。新活动可以撤销，不会直接覆盖之前下载的项目文件。

## 常用动效起点

| 元素 | 动作 | 幅度起点 | 时间建议 |
| --- | --- | --- | --- |
| 椰叶、丝带 | 左右摇摆 | 1°–3° | 常驻，支点放在连接位置 |
| 产品 | 自然悬浮 | 6–14 px | 0.6 秒入场，4.0 秒开始退场 |
| 促销标题 | 大促弹跳 | 25–45 px | 5 秒内重复 1–2 次 |
| 优惠标签 | 呼吸缩放 | 3%–8% | 与标题错峰 |
| 建筑、展台 | 静止 | 0 | 常驻 |
| 小猫整体 | 左右摇摆 | 1°–2° | 支点接近脚底 |

“每轮重复次数”使用整数，因此循环运动可自然接回开头。“动作错峰”让不同元素不必同时起伏。入场与退场方式设为“无”时，元素整轮常驻。

## 手机分开与放大

选择任一产品图层，可单独改变大小、位置和旋转。产品的“靠近 / 分开 / 一键并排”控制画面中前两个用途为“产品”的图层。如果产品数量更多，直接拖动各自位置。

替换宽高比例差别很大的产品后，可点“一键并排”重新计算距离。放大后向下移动一点，避开系列标题和口号。也可以改变图层顺序，让一个产品在另一个前面。

## 新图片的抠图与旋转

1. 添加或替换图片，选中该图层，在右侧点击“抠图 / 去底”。视频没有此选项。
2. 白底、绿幕或相近底色可点击“自动去纯色底”。也可使用“点选背景”，点击要移除的颜色；容差越高，去除的相近颜色越多。“只去除连通区域”可保护被主体包围的同色细节。
3. 复杂背景用“圈选保留”沿主体轮廓逐点点击，再点“完成圈选”（或双击结束）。圈外变透明。用“擦除 / 恢复”画笔处理细节；误操作可撤销，或恢复本次打开时的原图。
4. 需要时加 1–2px 边缘柔化。棋盘格代表透明背景，不会导出。点“应用到图层”保留布局与动效，也可单独“下载透明 PNG”。抠图处理大图时，最长边最多 2048px，保持完整画布边界以避免位置偏移。
5. 旋转可以输入精确角度、使用 ±90° 和归零按钮，或拖动预览中选框上方的圆点。按住 Shift 可按 15° 对齐。四个角点等比例缩放，拖动图片内部移动位置。

抠图为离线颜色去底与手工选区功能，不会自动识别复杂背景中的主体或补画缺失部分。若素材本身没有透明背景，先处理后再加动效；透明 PNG 可以直接使用。

## 固定预览与图层设计

中间预览始终留在窗口中。鼠标放在左侧图层列表滚动，只滚动图层；放在右侧属性区滚动，只滚动参数。窄屏通过“图层 / 属性与动效”切换下方面板，预览保持在上方。

图层列表上方对应画面前方。拖动图层到另一行上方或下方即可排序，黄色线提示落点；也可用“上移一层 / 下移一层”按钮或 Alt + ↑ / ↓。顶部可切换列表与缩略图。双击名称跳到名称输入框；圆形按钮控制显示，方形按钮锁定画布操作。排序、隐藏、锁定和抠图均随项目保存。

## 保存区别

| 操作 | 保存内容 | 下次如何打开 |
| --- | --- | --- |
| 保存项目 | 图片、文字、布局、全部动画参数 | 编辑器 → 打开项目 |
| 保存独立 HTML | 当前项目与整个编辑器 | 双击文件 |
| 导出 MP4 / WebM | 纯活动画面视频 | 直播软件中循环播放 |
| 保存这一帧 | 无编辑框的 PNG | 作为静态背景或封面 |
| 自动草稿 | 当前浏览器中的备份 | 点击恢复草稿 |

更改循环总时长会按比例调整各元素的入退场时间；重复次数保持不变。

## 透明图与动画的边界

编辑器移动和旋转的是图片图层，不会自动生成产品背面或补齐被裁掉的部位。需要不同机身角度时，准备不同角度的产品图片，分别设置进入和离开时间。需要手臂、叶片等局部运动时，先把它们输出为独立 PNG。
