# 给 GPT 的素材生成指令

下次直接把下面的活动信息填写后发给 GPT。无需让它生成完整视频；先得到分开的图片，再在编辑器中加动画。

## 总指令

```text
我要为 TikTok 电商直播制作 9:16 的 campaign 背景。
活动名称：[11.11 / Payday Sale / Ramadan / 新品首发]
品牌：[品牌名称]
产品：[产品名称]
主色：[颜色]
主题环境：[例如巴厘岛、城市夜景、未来科技展台]
需要保留的直播人物区域：[例如画面中下方]
画面风格：[例如写实 3D、金属光泽、柔和自然光]
活动文案：[可留空，后续我会在 HTML 里输入]

请为可编辑的 HTML 动效项目输出独立素材。
每个图片文件只放一个可独立动画的元素，不要合成整张海报。
请保持同一视角、光源方向和视觉风格。

分别输出：
1. background.png：1080×1920，只有场景和舞台，不能有促销标题、产品、logo、小猫或前景装饰。
2. headline.png：活动主视觉，透明背景，主体完整，不裁切；建议 1600 像素宽。
3. product-a.png：产品 A 的完整单品图，透明背景，建议 1600–2400 像素高。
4. product-b.png：产品 B 的完整单品图，同样要求。
5. decor-left.png：左侧装饰，透明背景，建议 1200 像素高。
6. decor-right.png：右侧装饰，透明背景，建议 1200 像素高。
7. mascot.png：完整吉祥物，透明背景，建议 1600 像素高。
8. badge.png：可选的优惠标识，透明背景。

透明背景必须是真正的 alpha 通道，不能把棋盘格或白底画进图片里。
主体四周留约 5%–10% 空间，不要过多透明留白。
不要在背景里重复绘制任何将单独输出的元素。
普通价格、产品名称、日期、活动口号留给 HTML 文字图层输入。
若某张图片无法一次输出，请按文件逐一生成，不要用一张拼图代替。
```

## 需要更细的独立动作时

把一组复杂主视觉进一步拆开，例如 `sale-number.png`、`ribbon.png`、`logo.png`。在编辑器里每张图片各建一个图层。

吉祥物需要真正挥手时，应另外输出身体和手臂，并让关节附近留出重叠区域。把手臂作为独立图层，设置支点和摇摆动画。只提供一张完整小猫图片时，编辑器能做整只小猫的悬浮、摆动与出入场。

## 产品图特别要求

```text
请沿用我提供的官方产品图外观：镜头数量、位置、边框、配色、品牌标志保持一致。
输出完整产品轮廓的透明 PNG，不要裁掉底部或侧边。
我只需要产品图层；不需要背景、价格、说明文字或新增机身细节。
```

完整官方透明产品 PNG 最适合直接使用。本项目中的两款手机来自你提供的产品海报；蓝色手机沿用了原图局部裁切，可在这里换成更完整的产品素材。

## 文件规格速查

| 类型 | 规格 | 编辑器中的操作 |
| --- | --- | --- |
| 背景 | 1080×1920，PNG / JPG / WebP | 点“背景” |
| 产品、装饰、logo | PNG 真透明，主体完整 | 选中图层 → 替换素材 |
| 新元素 | 独立 PNG，四周少量留白 | 点“＋图片” |
| 普通文字、价格 | 直接提供文字 | 点“＋文字” |
| 视频背景 | MP4 / WebM，无声，建议与项目同长且首尾衔接 | 点“背景” |

建议图片单边不超过 4096 像素，每个文件小于 40 MB。编辑器支持最多 100 个图层；活动主视觉通常 10–20 层更容易管理。
