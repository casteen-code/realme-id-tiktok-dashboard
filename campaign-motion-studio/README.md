# Campaign Motion Studio · 活动背景工坊

把 GPT 生成的图片变成可反复换素材的直播动效背景。打开 `index.html`，换图、拖动元素、调整动画，然后导出视频。日常使用不需要安装 Node.js，也不需要运行服务器。

这次 realme 9.9 项目已整理为 **14 个独立图层的示例**：背景、两侧巴厘岛门、两组椰叶、小猫、展台、大促主视觉、闪电、系列名称、新品标签、口号、两款手机。

## 下次做新活动

1. 把 [GPT 素材生成说明](docs/GPT-ASSET-PROMPTS.md) 发给 GPT，生成背景与透明 PNG 元素。
2. 双击 `index.html`。继续现有版式时，选择一个元素，点击 **替换素材**；做全新活动时，点击 **新活动**。
3. 点击 **背景** 更换 9:16 底图。用 **＋图片 / ＋文字 / ＋闪电** 添加元素。
4. 图片带背景时，点 **抠图 / 去底**，完成后点 **应用到图层**。在预览中拖动位置，拖动四角缩放、上方圆点旋转；右侧调整循环动作、幅度及入退场时间。
5. 点击 **保存项目**，下载包含所有素材的 `.campaign.json`。下次点击 **打开项目** 恢复。
6. 点击 **导出 MP4 / WebM**，将视频放进直播软件的媒体源并循环播放。

**保存独立 HTML** 会把当前活动、图片和编辑器一起保存。把这个文件带到另一台电脑，也能继续编辑。HTML 是编辑工具，导出的视频只包含活动画面。

## 可以分别修改什么

| 对象 | 可改内容 |
| --- | --- |
| 背景 | JPG、PNG、WebP 或 MP4 / WebM；底色 |
| 每个图片元素 | 换图、去底、圈选、擦除 / 恢复、位置、宽高、缩放、旋转、翻转、不透明度、支点、阴影 |
| 文字 | 内容、字号、颜色、加粗、位置和动效 |
| 循环动作 | 静止、悬浮、摇摆、呼吸缩放、大促弹跳、明暗闪动 |
| 出入场 | 方向、淡入淡出、缩放、开始时间、持续时间、移动距离 |
| 图层关系 | 增加、复制、删除、显示 / 隐藏、锁定、拖拽排序、列表 / 缩略图切换、双击名称重命名 |
| 产品组合 | 每个产品独立调整；前两个产品可一键靠近、分开或并排 |
| 整场 | 活动名称、2–15 秒时长、底色；固定 1080×1920 / 30fps |

替换图片会保留原来的布局和动画，并按原高度适配新图比例。改宽度或高度时，图片会保持原始长宽比。背景使用 9:16 素材，避免填满画布时拉伸。

## 图片处理与固定工作区

选中图片 → **抠图 / 去底**。白底、绿幕等纯色背景先用 **自动去纯色底**；也可以点选背景颜色，调节容差。复杂背景使用 **圈选保留**、**擦除** 和 **恢复** 画笔，配合边缘柔化。处理结果可以下载为透明 PNG，或直接应用到当前图层，位置、尺寸、旋转与动画保持不变。可以撤销还原。

这些工具在本地处理，使用颜色选区和人工修整，不含 AI 主体识别。大图会在抠图时适配至最长边 2048px；不自动裁掉透明边距，避免元素跳位。视频图层暂不支持抠图。

桌面端中间预览固定在窗口内；左侧图层列表和右侧属性面板各自滚动。列表上方代表画面前景，拖动图层可改变遮挡顺序，也可用上移 / 下移按钮或 `Alt + ↑ / ↓`。窄屏在固定预览下方切换“图层”和“属性与动效”。旋转可输入角度、使用 ±90° / 归零按钮，或拖动选框上方圆点；按住 `Shift` 时按 15° 对齐。选框与操作点不出现在导出图片或视频里。

## 这次项目的两种保留方式

- `index.html`：通用编辑器，默认是可复用的 **分层重构版**。椰叶、门、小猫等可以独立替换，与原合成背景在细节上会有差异。
- `examples/realme-99-legacy.html`：保留你之前喜欢的编辑器，包括 1.5 倍默认手机尺寸、2.4 倍上限和两机间距按钮。它的环境装饰仍在背景视频里。

大促主视觉 `headline.png` 包含“9⚡9 + SUPER DEALS”整组设计，可整组换成下一场活动的 PNG。若想把数字、丝带、文字分别动画，让 GPT 分别输出图片，再各自添加为独立图层。普通文案直接使用文字图层，更方便改字。

## 开发与验证

构建只用 Node.js 内置模块：

```bash
node scripts/build.cjs
```

开发检查：

```bash
npm install
npm test
npm run build
```

用另一份配置构建独立页面：

```bash
node scripts/build.cjs --project examples/realme-99.campaign.json --out index.html
```

可选的本地出图与视频渲染，需要 `@napi-rs/canvas`，视频另需 FFmpeg：

```bash
npm run preview
npm run render
```

命令行渲染器处理图片和文字图层；含视频素材的项目请从 HTML 编辑器导出。命令行可用 `--font /path/to/font.ttf` 指定与页面一致的字体。

## 当前验证范围

22 项自动检查覆盖元素独立性、首尾循环、入退场、图层命中、项目序列化，以及非浏览器 DOM 环境中的换图、两机间距、旋转 / 缩放操作点、拖拽排序、保存 HTML 后重新载入、新建 / 撤销 / 重做。抠图同时通过像素检查和 DOM + 原生 Canvas 集成检查，确认透明 PNG 输出与应用 / 取消 / 撤销不会改变布局和动效。示例画面由同一引擎渲染，已有示例视频检查了分辨率、时长和帧数。

编辑器保持纯 HTML / Canvas。当前制作环境无法打开本地 HTML 进行浏览器实测，浏览器内的文件选择、实际视频编码和草稿持久化仍取决于用户浏览器。支持 AVC WebCodecs 时提供 MP4，否则提供 WebM 实时录制；后者的时长与帧率会受机器负载影响。

所有素材在本地处理。浏览器草稿只是辅助恢复，跨设备请使用“保存项目”或“保存独立 HTML”。
